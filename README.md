# 🎬 ServerWatchParty - Real-Time Streaming Synchronization

Server cloud ad alte prestazioni per la sincronizzazione real-time di film e serie TV con **StreamingCommunity App**.

## 🚀 Deploy Gratuito su Render.com in 1 Click

1. Crea un account gratuito su [Render.com](https://render.com).
2. Clicca su **New +** e seleziona **Web Service**.
3. Collega la tua repository GitHub `ServerWatchParty`.
4. Render rileverà automaticamente Node.js:
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Plan**: `Free`
5. Clicca **Create Web Service**.

Il tuo server sarà attivo con URL HTTPS/WSS gratuito, ad esempio:
`https://server-watchparty.onrender.com`

---

## 🛠️ Funzionalità
- **WebSocket & Socket.io Engine**: Sincronizzazione istantanea con latenza <50ms tra amici su reti diverse.
- **REST State API**: Endpoint per interrogare e aggiornare lo stato di una stanza.
- **Auto Clean-up**: Pulizia automatica delle stanze inattive dopo 12 ore.
